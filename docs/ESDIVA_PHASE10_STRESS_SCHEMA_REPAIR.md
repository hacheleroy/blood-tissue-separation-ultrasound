# Phase-10 stress scorer configuration repair

26 October 2026. The [pre-RF freeze](ESDIVA_PHASE10_STRESS_FREEZE.md) was committed at `f12dc0d`. After RF generation had begun and the first scene's wide IQ replay had completed, the first scoring call raised `KeyError: 'evaluator_only_blood_to_tissue_roi_power_max'` **before producing any score or mode selection**. The stress config had already set both core and wide source-purity maxima to **0.1** in `source_eligibility`, and the frozen parent candidate sets the same maximum. The copied scorer expected that value under a top-level key.

This repair adds only the top-level **0.1** alias to the primary config. It updates the counterfactual config's parent SHA-256 pointer to the repaired primary config. No acquisition, selector, numerical source, method, scene, seed, score frame, or gate value changes. The aborted scoring call generated no `score.json`; the first scene's acquisition report and replay audit were retained. This correction was committed before any new scene's filter score or mode output was inspected. The first RF acquisition predates this schema repair, so the corrected config is **not** represented as a strict pre-RF byte freeze. The original commit and these exact changes remain visible in history.
