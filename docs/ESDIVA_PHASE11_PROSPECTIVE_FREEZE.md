# Phase 11: independent adaptive RF bank frozen before acquisition

26 October 2026. This [configuration](../configs/esdiva_phase11_prospective.json), [adaptive context](../examples/esdiva_phase11_adaptive.py), [scorer](../examples/esdiva_phase11_prospective_score.py) and [reviewer](../scripts/review_esdiva_phase11_prospective.py) are committed **before RF generation** for seeds **3907** and **3919**. The only development RF is the now-seen 3607/3619 stress bank. The fixed-strength grid had no all-scene pass; the adaptive first-64-frame rule has a narrow development pass and is evaluated here without retuning, replacement or cherry-picking.

Each new scatterer cloud has exactly five scenes: stationary fast, rigid fast, rigid slow, smooth slow and smooth zero, with flow scales 1, 1, 0.02, 0.02 and 0. The eSDIva upstream commit, 10% scatterer tier, 16 stationary prior calibration frames, 80 evaluation frames, true transmit angles 0°/−5°/+5°, RF source separation, noise replay, 32×16 wide IQ and eight-row core are inherited without change. Score frames 64–79. Source tissue masks must have 192 wide and 40 core pixels; evaluator-only blood/tissue contamination must be ≤0.1 in both. Prior-calibration coherence and bounded gain gates are unchanged. A failed input scene retains a report but no filter ranking.

The frozen phase-10 mode selector still uses the first 64 mixture frames and prior calibration. If it requests reference and the prior core amplitude safeguard ≥0.9 passes, the old reference context is used without any new strength fit. Otherwise the hybrid uses the first-64-frame **mixture-only** magnitude validation gain `g`: `w = clip((g−0.25)/0.20,0,1)`, phase fraction `1−0.5w`, and shift scale `0.25+0.5w`. The same chosen strengths apply to the evaluator's separately refitted tissue-plus-noise background. The selector and strength never read isolated blood, isolated tissue or known displacement.

The parent method settings and limits are unchanged. In **every** eligible scene, both SVD cut 1 and Axis 1 cut 1 must have selected-minus-no-motion paired added-blood IQ NRMSE ≤+0.020; selected and no-motion roundtrips must be ≤1×10⁻¹⁰. The selected/no-motion refitted-background tissue-power ratio must be ≤0.900 in rigid fast, rigid slow and smooth slow. Stationary fast and smooth zero still report tissue ratios without that moving-tissue suppression gate. In **both** slow scenes per seed, the uncorrected Axis 2 rank-4/cap-0.4 control needs blood NRMSE ≤0.700 and tissue leakage ≤0.180. All ten scenes and source checks must pass for the prospective numerical gate; any missing or failed scene stays a failure. Natural reference-mode coverage is a separate descriptive outcome and is never manufactured by forcing the branch.

A numerical pass would support this candidate only in the pinned acoustic simulator on two independent clouds. It would not establish preservation of all physical flow, nor revise the already archived phase-10 reserve/stress decisions. Physical transfer remains conditional on measured three-view scanner, structural, matched control, independent motion and flow data.
